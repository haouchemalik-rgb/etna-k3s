Bienvenue sur la documentation complète du projet **ISR-CLO4**.

Ce projet déploie une architecture complète sur Kubernetes comprenant :
- Stockage de secrets **Vault**
- Base de données **MariaDB**
- Application **WordPress**
- **Supervision** (Prometheus / Grafana / Blackbox)
- **Logging** (Loki / Promtail)
- Ce site de **documentation** (Hugo)

Utilisez le menu de gauche pour naviguer.
